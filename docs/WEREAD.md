# 微信读书资料关联

入口：设置 → 外观 → 关联微信读书。默认关闭；使用用户自己的官方 API Key。
获取入口：https://weread.qq.com/r/weread-skills

## 使用

- 书籍详情 → 关联微信读书，按书名、作者搜索；选择候选后核对 ISBN、译者、
  出版社、出版时间，明确确认后绑定。缺失信息标记为未提供，不推定同版。
- 可更换或解除关联；不覆盖“我的评分／书评”。封面、书名作者、推荐值及
  推荐／一般／不行分布集中展示；简介默认显示并附出版信息。宽屏左右排，
  手机及大字号上下排，沿用本地详情页标题字体。
- 详情先读已存缓存；首次展开书评、热门划线自动加载，空结果也缓存，
  再次展开不重复请求。两项同时展开会依次加载，保留手动刷新及失败重试。
  旧版误丢弃推荐值且已有评分人数的缓存在打开详情时尝试补取一次资料。
  最多缓存 200 条公开书评、官方返回的前 20 条热门划线，更多内容可到微信读书查看。
- 书评及简介仅显示文本，不执行 HTML。热门划线仅供参考，不写入本地笔记，
  不映射本地页码或选区。封面和简介分别预览、确认后采用。
- “在微信读书打开”只使用接口返回的受信任链接；缺失时禁用，不猜测链接。

## 数据与同步边界

- 请求固定发送到官方 `https://i.weread.qq.com/api/agent/gateway`，
  使用 Bearer Key、平铺参数和 `skill_version=1.0.5`。
  只调用 search、book/info、review/list、book/bestbookmarks。
  不上传正文、笔记、个人书评，不调用扫码移动端私有接口。
- 官方网关实测 `newRating=836` 表示 83.6%，在网络边界转换为百分值；
  本地缓存、备份和同步不再重复除十。评分分布只保存公开 good/fair/poor
  计数，不保存个人评分字段。字数在接口返回时展示；未返回的阅读人数、
  会员状态等不从网页抓取或推测。封面展示不替换本地封面。
- 开关按设备保留。密钥保存在应用私有偏好设置中，不写运行日志，不进入公开缓存。
- API Key 随全局设置迁移时，必须勾选包含账号密钥；云端迁移沿用现有
  “敏感数据同步”开关、独立加密密码及 AES-256-GCM。普通书籍同步不携带明文密钥。
  旧版客户端不认识新增密钥字段，所有参与敏感设置同步的设备应升级后再同步。
  老备份未包含此字段时不会清空本机密钥；明确保存空值可以同步清除。
- 关联与公开资料是独立 sidecar：`modu/weread-metadata-v1/<原书 MD5>/`。
  未下载或已删除的原书不下载 sidecar。书籍下载后、正常同步及释放原书之前处理。
  不改数据库同步协议，不覆盖个人评分／书评。
- 关联有独立版本，解除关联保留墓碑；不同关联版本不混用缓存。相同关联按分区
  更新时间合并。不可变快照使用 SHA-256 校验，上传后读回验证，再回收已合并输入。
  凭据与公开缓存分开处理；关闭资料查询不自动关闭用户已启用的敏感设置同步。

## 核验

官方接口依据：
https://github.com/Tencent/WeChatReading/tree/main/skills

模拟接口测试覆盖请求、字段、评分单位、错误脱敏、跳转域名、独立缓存、
更换／解除关联、并发刷新、跨设备及原书下载条件、备份过滤和加密密钥往返。
界面测试覆盖窄／宽屏、关联确认、替换简介确认和关闭后丢弃迟到响应。
真实账号接口可用性、配额以及第三方数据展示授权仍需使用者确认。
