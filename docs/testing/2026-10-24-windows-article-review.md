# Windows article review — 2026-10-24

Source: user-supplied PDF of [10 款好评软件，能装的只有 5 款](https://mp.weixin.qq.com/s/q2I1uZJKmlcQgZTg8j9TaA), especially pages 7–10. The article tested Windows x64 **1.2.9**, dated October 13; the PDF print date is October 24. Its statements do not establish current-version behavior. No private book data was needed for this review.

## Findings and changes

| Article observation | Current evidence and disposition |
| --- | --- |
| `/S` leaves an unattended installer waiting for input. | The release generator uses Inno Setup and previously had no guard for the NSIS option. Add an exact, case-insensitive `/S` check in `InitializeSetup`, returning false before creating the wizard and logging the supported command. Preserve normal GUI installation and native silent options. No automatic relaunch or silent-mode substitution. |
| Git Bash rewrites slash-prefixed arguments. | Document `MSYSNOPATHCONV=1`, native Inno flags, PowerShell process waiting, log files and checks of exit status, installed file and version. An installer cannot repair a command that the shell has already rewritten. |
| GDI window captures are white. | The article explicitly did not assess the visible reading experience. `windows/runner/flutter_window.cpp` already shows the native window after the first frame and requests a redraw. `window_position_validator.dart` already checks saved coordinates against attached displays. No new rendering defect is established; document capture troubleshooting without changing the renderer. Native visible-window behavior still needs Windows evidence if reported as a separate failure. |
| Installer is unsigned. | The release generator has no Authenticode signing step; existing release documentation discloses this. SHA-256 verifies downloaded bytes against the published digest and is not a publisher signature. No certificate was created or signing claim added. |
| A vector model is bundled. | Current packaging rejects bundled embedding weights; model metadata/manifests remain bundled and weights are downloaded/imported separately. See `docs/RELEASING.md` and `lib/page/settings_page/vector_model.dart`. The old release description is not a current packaging defect. |
| A local HTTP service runs. | `book_player_server.dart` binds explicitly to `127.0.0.1`, including its random-port fallback. Preserve this local resource-serving path. |

The change affects installers generated by `scripts/release/native_installers.py`, used by current packaging and native repackaging. Previously published binaries and the older standalone `scripts/build_windows_exe.ps1` / `.iss` path are not modified. No historical release metadata was rewritten.

## Validation

- `PYTHONPATH=test python3 -m unittest windows_install_version_test release_package_test`: **49 tests passed** on macOS. Coverage includes both architecture scripts, rejection diagnostics in UTF-8/UTF-16LE, incorrect exit status, unexpected installation, unrelated failure diagnostics and timeout propagation. These are generator/orchestration checks, not execution of Pascal on Windows.
- Added rejection checks for both `/S` and `/s` to the existing disposable Windows CI installation gate. It requires exit code 1, a specific corrective diagnostic and no target directory within 30 seconds, then continues the existing supported silent install, payload/version, launch/close and uninstall checks.
- `git diff --check`: passed.
- Not run here: Windows compilation/installation, Windows screenshot capture or pixel-level reading tests. No package, device installation, push or release was performed for this review.

Implementation follows the official Inno Setup [initialization callback](https://jrsoftware.org/ishelp/topic_scriptevents.htm), [command-line options](https://jrsoftware.org/ishelp/topic_setupcmdline.htm) and [exit codes](https://jrsoftware.org/ishelp/topic_setupexitcodes.htm). Returning false aborts initialization; the correct unattended invocation is `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-`.
