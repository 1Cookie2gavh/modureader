# OCR 重排翻页修复（2026-10-12）

## 复现与原因

- 荣耀 LGE-AN10 / Android 15，原包 `1.2.7-preview.6+10114`。
- 书架内《改良与革命：辛亥革命在两湖》PDF，共 362 页。在全屏 OCR 重排第 53 页点击下一页，页码变成 54，正文仍是 53，并提示重排失败。
- 这不是「提取文字」弹窗的预览翻页路径。重排成功后还会调用 `goToDocumentOriginalPage` 同步原书阅读位置。
- 该桥接误把渲染器使用的 `{index: page}` 传给 `View.goTo`；后者接受数字页码、CFI 或文档链接。PDF 把对象当链接解析时报错，因此整个重排事务没有提交。
- 修改为传入数字页码；保留边界校验、失败时不提交进度、不新增跳转历史的行为。文字重排、OCR 重排与扫描 EPUB 共用此修复。

## 回归

- 新增执行真实桥接、View 导航方法与 PDF 链接解析器的回归测试：修复前失败，修复后通过。包含前后翻页、首页、非法页码、导航失败和历史保护；扫描 EPUB 链接契约同测。
- 定向 JS 导航／PDF 渲染测试 39 项通过；完整阅读器 JS 回归 483 项通过。
- Flutter 重排与文字提取面板测试 36 项通过。
- 未改变 OCR 模型、识别内容、AI 发送行为、书库或笔记数据结构。
