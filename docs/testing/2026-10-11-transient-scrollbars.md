# 半透明滚动条接入

- 全局 `AppScrollBehavior` 覆盖 Flutter 列表、网格、设置、综合查询、对话和弹窗。仅纵向右侧，横向滑动保留但不显示滚动条；8 px、46% 不透明度、最短 48 px；停止滚动 1.2 秒后隐藏。控件旁留出拖动区域。
- 每个装饰控制器仅绑定所属 Scrollable 的位置，避免共用 PrimaryScrollController 的并排列表报错或互相跳动；不改变原页面控制器。
- 阅读设置、PDF 裁边和翻译现有手工滚动条使用相同组件，并关闭重复自动装饰。
- 内嵌词典原版、网页翻译和联网搜索非阻塞加载网页装饰，不新增 JS 桥、网络请求或文件权限。网页自身策略可拒绝装饰；不影响原页面加载与滚动。跨域子框架不注入脚本。
- EPUB 连续滚动及 PDF 连续卷轴接入同一网页组件，支持拖动和键盘；PDF 缩放后的横向溢出仍可平移，不提供底部条。分页翻书不加滚动条。
- E-Ink/减少动画时取消淡入淡出，不取消自动隐藏；内容无需滚动时不显示。

## 验证

取消横向滚动条后的定向复验：10 项 Flutter 滚动条测试与 61 项网页/阅读内核测试通过，静态检查无诊断。覆盖横向列表仍可滑动、横向溢出不显示滚动条，纵向拖动及自动隐藏保持正常。

Flutter 回归组 124 项通过：六个平台配置下显示/隐藏及触控笔拖动、并排/嵌套列表、综合查询、设置弹窗、PDF、词典、文件夹、远程书库、AI 流式对话和网页翻译加载。平台配置测试不是各平台实机验收。

网页及阅读内核测试覆盖滚动条拖动、销毁、键盘、RTL、嵌套滚动、E-Ink、连续章节、PDF 定位与页切换。`flutter analyze --no-pub` 无诊断，`git diff --check` 通过。

仅更新阅读网页资源，没有生成安装包、安装到设备或发布。Webpack 仍有原有 3 条针对 ES5 目标的 async/await / topLevelAwait 兼容性警告；新增滚动条不依赖异步模块。真实触控笔、系统 WebView 及第三方网站行为仍需实机确认。
