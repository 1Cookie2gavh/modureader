## 本次优化

连续滚动渲染器的 `setStyles` 原本即使所有已加载章节的 CSS 都未变化，也无条件调用 `render()`，重复布局已加载章节。现在只有至少一个文档样式确实改变时才调用该次布局；字体等待、真实字体/字号/排版变化、分页和导航行为仍保留。适用于普通设备及使用连续滚动的 E-Ink 设备。

新增回归先复现失败：20 次相同样式使 render 次数从 1 增至 21；修复后保持 1。**减少的是这一路径上的重复排版次数，不是整机耗时降低百分比。** 主代码仅增加样式变化判断，未增加依赖、缓存或削减功能。生产 `dist/bundle.js` 已重建并包含在实测 APK 中。
