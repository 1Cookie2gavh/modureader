# Homepage screenshots

## Modu 1.3.0

The current Chinese and English homepages use `showcase/v1.3.0/`: 21 feature panels in each language, all 1536 × 1024. The artwork combines a designed ivory/sage background, localized headings, actual phone screenshots, and Mac presentations based on the running application. Ordinary demo prose and CSS effects are rendered illustrations; interface controls, query results, metadata and AI dialogs are composited from real screenshots, not regenerated. Both language editions use identical interface pixels below the localized heading.

The composition uses a large, approximately 1.3:1 Mac window beside a foreground phone. Ordinary prose is single-column; PDF original/reflow comparison keeps two panes. AI and query interfaces retain their actual centered popup presentation. WeRead uses only the authorized public metadata panel; the bookshelf contains only original demo books. Raw captures are not published because areas outside approved crops may contain personal information.

The user authorized sending the original demo chapter to DeepSeek for the pictured summary. No private book or note was sent for this demonstration. The screenshot preserves the returned answer rather than substituting an invented response.

## Composition brief

The built-in image-generation tool supplied the approved background and demo-page renderings. Final assembly used user-authorized deterministic screenshot compositing. Brief: pale ivory with soft sage foliage shadows, bold black heading at upper left, black Modu wordmark at upper right, larger Mac view, phone settings at left, soft shadows, readable single-column prose, and no invented controls, credentials or personal results. CSS demonstrates supported styling; PDF comparison remains split; AI/query results use real centered dialogs. English editions translate only the promotional headline.
